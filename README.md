# 🏁 Amigo Karting — Générateur d'idées de publications

Un outil **prêt à l'emploi** pour trouver quoi publier sur les réseaux sociaux d'**Amigo Karting** (Gatineau, Québec) : idées stratégiques, recettes vidéo, scripts mot à mot, et recherche d'actualités — le tout dans **un seul fichier qui s'ouvre dans le navigateur**, sans rien installer.

## ▶️ Ouvrir l'app

**En ligne (le plus simple) :**
👉 **https://amigokarting.github.io/amigo-karting-publications/**

(Ajoute cette page à tes favoris ou à l'écran d'accueil de ton téléphone.)

**Sur ton ordinateur :**
1. Clique le bouton vert **« Code »** (en haut) → **« Download ZIP »**.
2. Décompresse, puis double-clique **`Idees-Publications-Amigo.html`**.

## ✨ Ce que ça fait

- **Générer** des idées intelligentes, adaptées au mois, sans répétition.
- Pour chaque idée : **objectif** 🎯, **angle malin** 💡, **moment idéal** ⏰, **légende** prête à copier, **hashtags**, **recette** complète et un **script vidéo / plan** scène par scène.
- **🔄 Nouvelles** : cherche les actualités pertinentes (karting, F1, événements locaux) directement sur internet — juste une connexion, aucune installation.
- **Favoris ❤️, groupes 📁, calendrier 📅, statut publié ✅, recommandations 🎯**.
- **Ajouter tes propres idées ➕**, **exporter / imprimer 📤**.
- Fonctionne **hors-ligne** (sauf la recherche de nouvelles) et **se répare en un clic** (menu ☰ → 🧹 Réinitialiser).
